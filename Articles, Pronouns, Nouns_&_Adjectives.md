# 🇩🇪 German Articles, Pronouns, Nouns & Adjectives

## 1. Nouns — Nomen

A **noun** is a person, place, thing, or idea.

| German     | English    | Gender    |
| ---------- | ---------- | --------- |
| der Mann   | the man    | Masculine |
| die Frau   | the woman  | Feminine  |
| das Kind   | the child  | Neuter    |
| der Tisch  | the table  | Masculine |
| die Schule | the school | Feminine  |
| das Haus   | the house  | Neuter    |

**Important:** German nouns always start with a **capital letter**.

---

# 2. The 3 German Genders

| Gender    | German   | Example  |
| --------- | -------- | -------- |
| Masculine | Maskulin | der Mann |
| Feminine  | Feminin  | die Frau |
| Neuter    | Neutrum  | das Kind |

There is also **Plural**:

> die Männer, die Frauen, die Kinder

# 3. Articles

German has **definite articles** (the) and **indefinite articles** (a/an).

### Definite Articles

| Gender    | Nominative | Akkusativ (direct) | Dativ (indirect) |
| --------- | ---------- | ------------------ | ---------------- |
| Masculine | **der**    | **den**            | **dem**          |
| Feminine  | **die**    | **die**            | **der**          |
| Neuter    | **das**    | **das**            | **dem**          |
| Plural    | **die**    | **die**            | **den**          |

### Indefinite Articles

| Gender    | Nominative | Akkusativ | Dativ     |
| --------- | ---------- | --------- | --------- |
| Masculine | **ein**    | **einen** | **einem** |
| Feminine  | **eine**   | **eine**  | **einer** |
| Neuter    | **ein**    | **ein**   | **einem** |

There is **no plural form of "ein"**.

---

# 4. Direct Object — Akkusativ

The **direct object** is the person or thing that directly receives the action.

Ask:

> **Wen?** = Whom?
> **Was?** = What?

### Example

> Ich sehe **den Mann**.
> I see **the man**.

Who is doing the action?

**Ich** → subject

What/who am I seeing?

**den Mann** → direct object → **Akkusativ**

Notice:

> der Mann → **den Mann**

The masculine article changes.

### More examples

> Ich kaufe **das Buch**.
> I buy the book.

> Ich sehe **die Frau**.
> I see the woman.

> Ich habe **einen Hund**.
> I have a dog.

---

# 5. Indirect Object — Dativ

The **indirect object** usually tells us **to whom** or **for whom** something is done.

Ask:

> **Wem?** = To whom? / For whom?

### Example

> Ich gebe **dem Mann** das Buch.
> I give the man the book.

**Ich** → subject
**das Buch** → direct object (Akkusativ)
**dem Mann** → indirect object (Dativ)

Another example:

> Ich gebe **der Frau** das Buch.
> I give the woman the book.

# 6. Pronouns — Pronomen

Pronouns replace nouns.

### Personal Pronouns

| German | English      |
| ------ | ------------ |
| ich    | I            |
| du     | you          |
| er     | he           |
| sie    | she          |
| es     | it           |
| wir    | we           |
| ihr    | you (plural) |
| sie    | they         |
| Sie    | you (formal) |

### Example

Instead of:

> Maeca lernt Deutsch.

We can say:

> **Sie** lernt Deutsch.

"Sie" replaces "Maeca."

---

# 7. Pronouns in Akkusativ

| Nominative | Akkusativ | English      |
| ---------- | --------- | ------------ |
| ich        | **mich**  | me           |
| du         | **dich**  | you          |
| er         | **ihn**   | him          |
| sie        | **sie**   | her          |
| es         | **es**    | it           |
| wir        | **uns**   | us           |
| ihr        | **euch**  | you          |
| sie        | **sie**   | them         |
| Sie        | **Sie**   | you (formal) |

Examples:

> Ich sehe **ihn**.
> I see him.

> Er liebt **sie**.
> He loves her.

> Sie hört **mich**.
> She hears me.

---

# 8. Pronouns in Dativ

| Nominative | Dativ     | English             |
| ---------- | --------- | ------------------- |
| ich        | **mir**   | to/for me           |
| du         | **dir**   | to/for you          |
| er         | **ihm**   | to/for him          |
| sie        | **ihr**   | to/for her          |
| es         | **ihm**   | to/for it           |
| wir        | **uns**   | to/for us           |
| ihr        | **euch**  | to/for you          |
| sie        | **ihnen** | to/for them         |
| Sie        | **Ihnen** | to/for you (formal) |

Examples:

> Ich gebe **ihm** das Buch.
> I give him the book.

> Sie hilft **mir**.
> She helps me.

> Wir geben **ihnen** das Geld.
> We give them the money.

# 9. Adjectives — Adjektive

Adjectives describe nouns.

Examples:

* groß = big/tall
* klein = small
* schön = beautiful
* alt = old
* neu = new
* schnell = fast
* langsam = slow
* gut = good
* schlecht = bad
* kalt = cold
* warm = warm

### Examples

> ein **großes** Haus
> a big house

> eine **schöne** Frau
> a beautiful woman

> ein **kleiner** Hund
> a small dog

The adjective ending can change depending on the **gender and case**.

---

# 10. Putting Everything Together

### Nominative

> **Der kleine Hund** ist schön.
> The small dog is beautiful.

**Der kleine Hund** = subject.

### Akkusativ

> Ich sehe **den kleinen Hund**.
> I see the small dog.

**den kleinen Hund** = direct object.

### Dativ

> Ich gebe **dem kleinen Hund** Wasser.
> I give the small dog water.

**dem kleinen Hund** = indirect object.

Notice the changes:

| Case       | Phrase               |
| ---------- | -------------------- |
| Nominative | **der kleine Hund**  |
| Akkusativ  | **den kleinen Hund** |
| Dativ      | **dem kleinen Hund** |

---

# ⭐ The Main Idea

Think of German sentences like this:

**Nominative** → Who is doing the action?

**Akkusativ** → Who/what receives the action directly?

**Dativ** → To whom/for whom?

And gender tells you which basic article you start with:

> **der** = masculine
> **die** = feminine
> **das** = neuter

Then the **case can change the article**:

> der → den → dem
> die → die → der
> das → das → dem
