# 🇩🇪 Komposita – Compound Words

**Komposita** (singular: **das Kompositum**) are **compound words**.

They are formed by joining **two or more words** together to create one new word.

## Examples

| Words                  | Compound             | Meaning     |
| ---------------------- | -------------------- | ----------- |
| die Hand + das Buch    | **das Handbuch**     | handbook    |
| die Schule + das Kind  | **das Schulkind**    | schoolchild |
| der Kaffee + die Tasse | **die Kaffeetasse**  | coffee cup  |
| das Haus + die Tür     | **die Haustür**      | house door  |
| die Arbeit + der Platz | **der Arbeitsplatz** | workplace   |

## ⭐ Important Rule

The **last word determines the gender** of the entire compound word.

### Example 1

**die Arbeit + der Platz → der Arbeitsplatz**

* Arbeit = work
* Platz = place
* **der Platz** is masculine
* Therefore: **der Arbeitsplatz**

### Example 2

**das Haus + die Tür → die Haustür**

* Haus = house
* Tür = door
* **die Tür** is feminine
* Therefore: **die Haustür**

## 🧠 Easy Rule to Remember

> **First word = adds meaning**
> **Last word = determines the gender and basic meaning**

### More examples

* **das Schlafzimmer** = bedroom
  `Schlaf + Zimmer`
* **die Zahnbürste** = toothbrush
  `Zahn + Bürste`
* **der Fußball** = football/soccer
  `Fuß + Ball`
* **das Wörterbuch** = dictionary
  `Wörter + Buch`

German can therefore create **very long words** by combining several words together!
