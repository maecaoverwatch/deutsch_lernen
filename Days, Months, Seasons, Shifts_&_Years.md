# 🇩🇪 Days, Months, Seasons, Shifts & Years

## 1. Die Wochentage — Days of the Week

| German         | English   |
| -------------- | --------- |
| **Montag**     | Monday    |
| **Dienstag**   | Tuesday   |
| **Mittwoch**   | Wednesday |
| **Donnerstag** | Thursday  |
| **Freitag**    | Friday    |
| **Samstag**    | Saturday  |
| **Sonntag**    | Sunday    |

### Example

> Heute ist Montag.
> Today is Monday.

> Morgen ist Dienstag.
> Tomorrow is Tuesday.

### "On Monday"

Use **am**:

> **am Montag** = on Monday

> Ich arbeite **am Montag**.
> I work on Monday.

# 2. Die Monate — Months

| German        | English   |
| ------------- | --------- |
| **Januar**    | January   |
| **Februar**   | February  |
| **März**      | March     |
| **April**     | April     |
| **Mai**       | May       |
| **Juni**      | June      |
| **Juli**      | July      |
| **August**    | August    |
| **September** | September |
| **Oktober**   | October   |
| **November**  | November  |
| **Dezember**  | December  |

### Example

> Ich habe im **Januar** Geburtstag.
> My birthday is in January.

Use **im** for months:

> **im Januar** = in January
> **im März** = in March
> **im Dezember** = in December

# 3. Die Jahreszeiten — Seasons

| German           | English     |
| ---------------- | ----------- |
| **der Frühling** | spring      |
| **der Sommer**   | summer      |
| **der Herbst**   | autumn/fall |
| **der Winter**   | winter      |

### Example

> Im Sommer ist es warm.
> In summer it is warm.

> Im Winter ist es kalt.
> In winter it is cold.

Use **im**:

> **im Frühling**
> **im Sommer**
> **im Herbst**
> **im Winter**

---

# 4. Schichten — Work Shifts

If by **"schichts"** you mean **work shifts**, these are the common German terms:

| German               | English             |
| -------------------- | ------------------- |
| **die Schicht**      | shift               |
| **die Frühschicht**  | early/morning shift |
| **die Tagschicht**   | day shift           |
| **die Spätschicht**  | late/evening shift  |
| **die Nachtschicht** | night shift         |

Examples:

> Ich arbeite in der **Frühschicht**.
> I work the morning shift.

> Ich habe heute **Nachtschicht**.
> I have the night shift today.

> Sie arbeitet in der **Spätschicht**.
> She works the late shift.

---

# 5. Das Jahr — The Year

**das Jahr** = year

### Asking about the year

> **Welches Jahr ist es?**
> What year is it?

> **In welchem Jahr?**
> In which year?

### Examples

> **im Jahr 2026**
> in the year 2026

> Ich bin **im Jahr 2000** geboren.
> I was born in 2000.

---

# 6. Saying Years

German normally reads years as a number.

### Examples

**1990**

> neunzehnhundertneunzig

**2000**

> zweitausend

**2005**

> zweitausendfünf

**2020**

> zweitausendzwanzig

**2026**

> zweitausendsechsundzwanzig

# 7. Useful Time Words

| German            | English              |
| ----------------- | -------------------- |
| **heute**         | today                |
| **gestern**       | yesterday            |
| **morgen**        | tomorrow             |
| **übermorgen**    | day after tomorrow   |
| **vorgestern**    | day before yesterday |
| **diese Woche**   | this week            |
| **letzte Woche**  | last week            |
| **nächste Woche** | next week            |
| **dieses Jahr**   | this year            |
| **letztes Jahr**  | last year            |
| **nächstes Jahr** | next year            |

⚠️ Remember:

**morgen** = tomorrow
**der Morgen** = the morning

# ⭐ Useful Question Words

| German                       | English               |
| ---------------------------- | --------------------- |
| **Welcher Tag ist heute?**   | What day is today?    |
| **Welches Datum ist heute?** | What is today's date? |
| **Wann?**                    | When?                 |
| **In welchem Monat?**        | In which month?       |
| **In welcher Jahreszeit?**   | In which season?      |
| **Welches Jahr?**            | Which year?           |

### Example conversation

> **Welcher Tag ist heute?**
> Heute ist Montag.

> **In welchem Monat sind wir?**
> Wir sind im September.

> **Welche Jahreszeit ist es?**
> Es ist Herbst.
