# 🇩🇪 German Regular & Irregular Verbs

## 1. What is a Verb?

A **verb (Verb)** describes an action, state, or occurrence.

Examples:

| German   | English      |
| -------- | ------------ |
| machen   | to do / make |
| lernen   | to learn     |
| sprechen | to speak     |
| wohnen   | to live      |
| sein     | to be        |
| haben    | to have      |
| gehen    | to go        |

---

# 2. Regular Verbs — Regelmäßige Verben

Regular verbs follow a **consistent pattern** when conjugated.

The verb has a **stem (Stamm)**. We add different endings depending on who is doing the action.

### Example: `machen` — to do/make

Stem = **mach-**

| Person       | Pronoun   | Ending | Conjugation | English        |
| ------------ | --------- | ------ | ----------- | -------------- |
| 1st singular | ich       | -e     | ich mache   | I do/make      |
| 2nd singular | du        | -st    | du machst   | you do/make    |
| 3rd singular | er/sie/es | -t     | er macht    | he/she/it does |
| 1st plural   | wir       | -en    | wir machen  | we do/make     |
| 2nd plural   | ihr       | -t     | ihr macht   | you do/make    |
| 3rd plural   | sie       | -en    | sie machen  | they do/make   |
| Formal       | Sie       | -en    | Sie machen  | you do/make    |

### Regular Verb Endings

| Pronoun   | Ending  |
| --------- | ------- |
| ich       | **-e**  |
| du        | **-st** |
| er/sie/es | **-t**  |
| wir       | **-en** |
| ihr       | **-t**  |
| sie/Sie   | **-en** |

# 4. Irregular Verbs — Unregelmäßige Verben

Irregular verbs **do not always follow the normal conjugation pattern**.

The change can happen in the **stem**, the endings, or both.

For beginners, the most important thing is to learn their forms individually.

### Example: `sein` — to be

| Person    | German   | English      |
| --------- | -------- | ------------ |
| ich       | **bin**  | I am         |
| du        | **bist** | you are      |
| er/sie/es | **ist**  | he/she/it is |
| wir       | **sind** | we are       |
| ihr       | **seid** | you are      |
| sie/Sie   | **sind** | they/you are |

Notice that `sein` doesn't follow the regular pattern at all.

# 6. Stem-Changing Verbs

Some German verbs are mostly regular, but the **stem changes with `du` and `er/sie/es`**.

### `sprechen` — to speak

| Person    | Conjugation  |
| --------- | ------------ |
| ich       | spreche      |
| du        | **sprichst** |
| er/sie/es | **spricht**  |
| wir       | sprechen     |
| ihr       | sprecht      |
| sie/Sie   | sprechen     |

`e → i`

### `lesen` — to read

| Person    | Conjugation |
| --------- | ----------- |
| ich       | lese        |
| du        | **liest**   |
| er/sie/es | **liest**   |
| wir       | lesen       |
| ihr       | lest        |
| sie/Sie   | lesen       |

`e → ie`

### `fahren` — to drive/go

| Person    | Conjugation |
| --------- | ----------- |
| ich       | fahre       |
| du        | **fährst**  |
| er/sie/es | **fährt**   |
| wir       | fahren      |
| ihr       | fahrt       |
| sie/Sie   | fahren      |

`a → ä`

# 7. Regular vs Irregular — Quick Comparison

### Regular: `machen`

**mach + endings**

> ich mache
> du machst
> er macht
> wir machen

The stem stays **mach-**.

### Irregular: `sprechen`

> ich spreche
> du **sprichst**
> er **spricht**
> wir sprechen

The stem changes.

# 8. Important Verb Groups

German verbs can be grouped into more than simply "regular" and "irregular."

| Type        | German               | Example      |
| ----------- | -------------------- | ------------ |
| Regular     | regelmäßige Verben   | machen       |
| Irregular   | unregelmäßige Verben | gehen        |
| Mixed       | gemischte Verben     | bringen      |
| Modal       | Modalverben          | können       |
| Separable   | trennbare Verben     | aufstehen    |
| Inseparable | untrennbare Verben   | verstehen    |
| Reflexive   | reflexive Verben     | sich waschen |

These groups become especially important when we study **past tense, perfect tense, and other German tenses**.

## ⭐ Key Idea

**Regular verbs:** follow a predictable conjugation pattern.

**Irregular verbs:** change their stem or form and need to be learned individually.

**Modal verbs:** express things like ability, necessity, permission, desire, or obligation.

We should learn them **in groups**, rather than trying to memorize thousands of verbs at once.
