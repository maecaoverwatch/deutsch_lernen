# 🇩🇪 German Verb Conjugation

## 1. What is Conjugation?

**Conjugation (Konjugation)** means changing a verb according to the **person** doing the action.

English:

> I work → She works

German:

> ich arbeite → sie arbeitet

---

# 2. Personal Pronouns

| German | English                  |
| ------ | ------------------------ |
| ich    | I                        |
| du     | you (informal, singular) |
| er     | he                       |
| sie    | she                      |
| es     | it                       |
| wir    | we                       |
| ihr    | you (informal, plural)   |
| sie    | they                     |
| Sie    | you (formal)             |

# 3. Regular Verb Conjugation

Let's use **machen** = "to do / make".

Remove **-en** from the infinitive:

**machen → mach-**

Then add the appropriate ending.

| Pronoun   | Ending | machen         |
| --------- | ------ | -------------- |
| ich       | -e     | ich **mache**  |
| du        | -st    | du **machst**  |
| er/sie/es | -t     | er **macht**   |
| wir       | -en    | wir **machen** |
| ihr       | -t     | ihr **macht**  |
| sie       | -en    | sie **machen** |
| Sie       | -en    | Sie **machen** |

### Regular Pattern

**Stem + ending**

> mach + e = mache
> mach + st = machst
> mach + t = macht
> mach + en = machen

---

# 4. Another Regular Verb: lernen

**lernen → lern-**

| Pronoun   | Conjugation |
| --------- | ----------- |
| ich       | lerne       |
| du        | lernst      |
| er/sie/es | lernt       |
| wir       | lernen      |
| ihr       | lernt       |
| sie/Sie   | lernen      |

The stem **lern-** does not change.

---

# 5. Irregular Verb Conjugation

Irregular verbs don't always follow the regular pattern.

## Example: sein — to be

| Pronoun   | sein     |
| --------- | -------- |
| ich       | **bin**  |
| du        | **bist** |
| er/sie/es | **ist**  |
| wir       | **sind** |
| ihr       | **seid** |
| sie/Sie   | **sind** |

There is no simple **stem + ending** rule here.

You learn these forms individually.

---

# 6. Irregular Verb: haben

**haben = to have**

| Pronoun   | haben     |
| --------- | --------- |
| ich       | **habe**  |
| du        | **hast**  |
| er/sie/es | **hat**   |
| wir       | **haben** |
| ihr       | **habt**  |
| sie/Sie   | **haben** |

Notice:

**haben → hast → hat**

The stem changes for **du** and **er/sie/es**.

# 7. Stem-Changing Irregular Verbs

Some irregular verbs change their **stem vowel** mainly with:

**du** and **er/sie/es**

### sprechen — to speak

| Pronoun   | sprechen     |
| --------- | ------------ |
| ich       | spreche      |

| er/sie/es | **spricht**  |
| wir       | sprechen     |
| ihr       | sprecht      |
| sie/Sie   | sprechen     |

**e → i**

| wir       | fahren     |
| ihr       | fahrt      |
| sie/Sie   | fahren     |

**a → ä**

---

### lesen — to read

| Pronoun   | lesen     |

# 8. Regular vs Irregular

|         | Regular        | Irregular               |
| ------- | -------------- | ----------------------- |
| Example | machen         | sprechen                |
| Stem    | stays the same | may change              |
| ich     | mache          | spreche                 |
| du      | machst         | **sprichst**            |
| er      | macht          | **spricht**             |
| wir     | machen         | sprechen                |
| Pattern | predictable    | must often be memorized |

---

# ⭐ The Main Rule to Remember

### Regular verbs

**Infinitive → remove -en → add endings**

> machen → mach + e/st/t/en/t/en

### Irregular verbs

The endings can still look familiar, **but the stem/form may change**.

> sprechen → spr**i**chst
> fahren → f**ä**hrst
> lesen → l**ie**st

And some verbs such as **sein** are completely irregular.

---

# 🧠 The German Conjugation Endings

For most regular verbs, memorize this:

| Person    | Ending  |
| --------- | ------- |
| ich       | **-e**  |
| du        | **-st** |
| er/sie/es | **-t**  |
| wir       | **-en** |
| ihr       | **-t**  |
| sie/Sie   | **-en** |

**e → st → t → en → t → en**

This pattern will become very useful as you learn more German verbs.

## The 3 main vowel-change patterns

e → i
sprechen → du sprichst

e → ie
lesen → du liest

a → ä
fahren → du fährst

au → äu
laufen → du läufst

These changes generally happen with du and er/sie/es in the present tense.
