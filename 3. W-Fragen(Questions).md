# 🇩🇪 German W-Fragen

## 1. The Main Question Words

| German         | Meaning              | Pronunciation    | Used for           |
| -------------- | -------------------- | ---------------- | ------------------ |
| **wer**        | who                  | **vair**         | Person             |
| **was**        | what                 | **vahs**         | Thing / action     |
| **wo**         | where                | **voh**          | Location           |
| **woher**      | where from           | **voh-hair**     | Origin             |
| **wohin**      | where to             | **voh-hin**      | Destination        |
| **wann**       | when                 | **vahn**         | Time               |
| **warum**      | why                  | **vah-room**     | Reason             |
| **wie**        | how                  | **vee**          | Manner / condition |
| **welche/r/s** | which                | **vel-khe/r/s**  | Choice             |
| **wie viel**   | how much             | **vee feel**     | Uncountable amount |
| **wie viele**  | how many             | **vee feel-eh**  | Countable things   |
| **wie lange**  | how long             | **vee lahng-eh** | Duration           |
| **wie oft**    | how often            | **vee oft**      | Frequency          |
| **wie spät**   | how late / what time | **vee shpait**   | Time               |
| **wie alt**    | how old              | **vee alt**      | Age                |
| **wessen**     | whose                | **vess-en**      | Possession         |
| **wem**        | to/for whom          | **vaym**         | Indirect object    |
| **wen**        | whom                 | **vayn**         | Direct object      |

---

# 2. Wer — Who?

Used when asking about a **person**.

**Wer bist du?**
→ Who are you?

**Wer ist das?**
→ Who is that?

**Wer kommt heute?**
→ Who is coming today?

---

# 3. Was — What?

Used when asking about a **thing, action, or information**.

**Was machst du?**
→ What are you doing?

**Was ist das?**
→ What is that?

**Was möchtest du?**
→ What would you like?

---

# 4. Wo — Where?

Used for a **location**.

**Wo wohnst du?**
→ Where do you live?

**Wo ist die Schule?**
→ Where is the school?

**Wo arbeitest du?**
→ Where do you work?

---

# 5. Woher — Where From?

Used to ask about **origin**.

**Woher kommst du?**
→ Where are you from?

**Woher kommen Sie?**
→ Where are you from? (formal)

---

# 6. Wohin — Where To?

Used when asking about a **destination or direction**.

**Wohin gehst du?**
→ Where are you going?

**Wohin fährt er?**
→ Where is he going/driving?

### Remember:

**Wo?** → Where? 📍
**Woher?** → Where from? ⬅️
**Wohin?** → Where to? ➡️

---

# 7. Wann — When?

Used to ask about **time**.

**Wann kommst du?**
→ When are you coming?

**Wann beginnt der Kurs?**
→ When does the course begin?

**Wann hast du Zeit?**
→ When do you have time?

---

# 8. Warum — Why?

Used to ask for a **reason**.

**Warum lernst du Deutsch?**
→ Why are you learning German?

**Warum bist du müde?**
→ Why are you tired?

A common answer begins with:

**Weil ...** → Because ...

---

# 9. Wie — How?

Used to ask about **how something is done or someone's condition**.

**Wie geht es dir?**
→ How are you?

**Wie machst du das?**
→ How do you do that?

**Wie heißt du?**
→ What is your name?

---

# 10. Welche — Which?

Used when choosing between things.

**Welche Sprache sprichst du?**
→ Which language do you speak?

**Welches Buch möchtest du?**
→ Which book do you want?

**Welchen Film möchtest du sehen?**
→ Which film do you want to watch?

> `welche / welches / welchen` changes according to the noun's grammatical gender and case.

---

# 11. Wie viel — How Much?

Used with things that are **not normally counted individually**.

**Wie viel kostet das?**
→ How much does that cost?

**Wie viel Wasser trinkst du?**
→ How much water do you drink?

---

# 12. Wie viele — How Many?

Used with **countable things**.

**Wie viele Geschwister hast du?**
→ How many siblings do you have?

**Wie viele Bücher hast du?**
→ How many books do you have?

---

# 13. Wie lange — How Long?

Used for **duration**.

**Wie lange arbeitest du?**
→ How long do you work?

**Wie lange bleibst du hier?**
→ How long are you staying here?

---

# 14. Wie oft — How Often?

Used for **frequency**.

**Wie oft lernst du Deutsch?**
→ How often do you study German?

**Wie oft gehst du ins Fitnessstudio?**
→ How often do you go to the gym?

---

# 15. Wie spät — What Time?

Used to ask for the **current time**.

**Wie spät ist es?**
→ What time is it?

---

# 16. Wie alt — How Old?

Used to ask about **age**.

**Wie alt bist du?**
→ How old are you?

**Wie alt ist dein Bruder?**
→ How old is your brother?

---

# ⭐ Basic German Question Structure

A very common structure is:

**W-Frage + Verb + Subject + ... ?**

Examples:

> **Wo** + **wohnst** + **du**?
> Where do you live?

> **Was** + **machst** + **du**?
> What are you doing?

> **Wann** + **kommst** + **du**?
> When are you coming?

> **Warum** + **lernst** + **du** Deutsch?
> Why are you learning German?

### Remember:

In a normal German **W-question**, the **verb usually comes second**.

**W-word → Verb → Person → Rest**

**Woher kommst du?**
**Was machst du?**
**Wann arbeitest du?**
