# 🇩🇪 Vorstellung – Introduction

## 1. Begrüßung — Greeting

|          | Informal | Formal     |
| -------- | -------- | ---------- |
| Greeting | Hallo!   | Guten Tag! |
| Reply    | Hallo!   | Guten Tag! |

---

## 2. Zustand — How are you?

|             | Informal                         | Formal                             |
| ----------- | -------------------------------- | ---------------------------------- |
| Question    | Wie geht es dir?                 | Wie geht es Ihnen?                 |
| Reply       | Mir geht es gut, danke. Und dir? | Mir geht es gut, danke. Und Ihnen? |
| Alternative | Sehr gut, danke!                 | Sehr gut, danke!                   |

---

## 3. Name — Name

|             | Informal             | Formal               |
| ----------- | -------------------- | -------------------- |
| Question    | Wie heißt du?        | Wie heißen Sie?      |
| Reply       | Ich heiße Maeca.     | Ich heiße Maeca.     |
| Alternative | Mein Name ist Maeca. | Mein Name ist Maeca. |

---

## 4. Herkunft — Where are you from?

|          | Informal             | Formal               |
| -------- | -------------------- | -------------------- |
| Question | Woher kommst du?     | Woher kommen Sie?    |
| Reply    | Ich komme aus Kenia. | Ich komme aus Kenia. |

---

## 5. Wohnort — Where do you live?

|          | Informal              | Formal                |
| -------- | --------------------- | --------------------- |
| Question | Wo wohnst du?         | Wo wohnen Sie?        |
| Reply    | Ich wohne in Nairobi. | Ich wohne in Nairobi. |

---

## 6. Hobby — Hobby

|                  | Informal                              | Formal                                |
| ---------------- | ------------------------------------- | ------------------------------------- |
| Question         | Was ist dein Hobby?                   | Was ist Ihr Hobby?                    |
| Reply            | Mein Hobby ist Zeichnen.              | Mein Hobby ist Zeichnen.              |
| Multiple hobbies | Was sind deine Hobbys?                | Was sind Ihre Hobbys?                 |
| Reply            | Meine Hobbys sind Zeichnen und Musik. | Meine Hobbys sind Zeichnen und Musik. |

---

## 7. Telefonnummer — Telephone Number

|          | Informal                              | Formal                                |
| -------- | ------------------------------------- | ------------------------------------- |
| Question | Wie ist deine Telefonnummer?          | Wie ist Ihre Telefonnummer?           |
| Reply    | Meine Telefonnummer ist 0712 345 678. | Meine Telefonnummer ist 0712 345 678. |

---

# 🗣️ Complete Informal Vorstellung

**A:** Hallo! Wie geht es dir?
**B:** Hallo! Mir geht es gut, danke. Und dir?
**A:** Auch gut, danke. Wie heißt du?
**B:** Ich heiße Maeca. Und du?
**A:** Ich heiße Anna. Woher kommst du?
**B:** Ich komme aus Kenia. Wo wohnst du?
**A:** Ich wohne in Nairobi. Was ist dein Hobby?
**B:** Mein Hobby ist Zeichnen. Wie ist deine Telefonnummer?
**A:** Meine Telefonnummer ist 0712 345 678.

---

# 🤝 Complete Formal Vorstellung

**A:** Guten Tag! Wie geht es Ihnen?
**B:** Guten Tag! Mir geht es gut, danke. Und Ihnen?
**A:** Auch gut, danke. Wie heißen Sie?
**B:** Ich heiße Maeca. Und Sie?
**A:** Ich heiße Anna. Woher kommen Sie?
**B:** Ich komme aus Kenia. Wo wohnen Sie?
**A:** Ich wohne in Nairobi. Was ist Ihr Hobby?
**B:** Mein Hobby ist Zeichnen. Wie ist Ihre Telefonnummer?
**A:** Meine Telefonnummer ist 0712 345 678.
