## Examples

| Number | German                              | Pattern         |
| -----: | ----------------------------------- | --------------- |
|     21 | einundzwanzig                       | 1 + and + 20    |
|     35 | fünfunddreißig                      | 5 + and + 30    |
|     99 | neunundneunzig                      | 9 + and + 90    |
|    213 | zweihundertdreizehn                 | 200 + 13        |
|  1,213 | eintausendzweihundertdreizehn       | 1000 + 200 + 13 |
|  1,523 | eintausendfünfhundertdreiundzwanzig | 1000 + 500 + 23 |

### Basic Formula

**Thousands + Hundreds + Units + und + Tens**

Example:

**1,523 → eintausend + fünfhundert + drei + und + zwanzig**
